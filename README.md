# 🏥 Hospital Patient Analysis

## Overview
Analysed 54,860 hospital patient records to understand 
admissions, treatments, outcomes and resource utilisation.

## Key Findings
- Arthritis is most common condition (9,207 patients)
- Average hospital stay is 15.5 days
- Emergency, Elective and Urgent admissions equally split
- Diabetes has highest avg billing (₹25,714)
- Middle-aged patients (40-59) admitted most frequently

## Tools Used
Excel → Python (Pandas) → SQL (SQLite) → Tableau
